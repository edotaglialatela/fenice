Schemes - Riemann solvers, TVD limiters, MUSCL

Riemann solvers

At each interface the solver receives the left and right conservative states $\mathbf{U}_L$, $\mathbf{U}_R$ and returns the numerical flux $\mathbf{F}^*$ that approximates the exact solution of the Riemann problem. With the unit normal $\hat{\mathbf n} = (n_x, n_y, n_z)$ and $V_n = \mathbf u\cdot\hat n$, the normal Euler flux is

$$\mathbf{F}\cdot\hat n = \bigl[\rho V_n,\ \rho u V_n + p n_x,\ \rho v V_n + p n_y,\ V_n(\rho E + p),\ \rho w V_n + p n_z\bigr]^\top$$

On a Cartesian mesh every face is normal to one axis, so the solvers take the axis (face_flux(UL, UR, axis, smax), axis 0/1/2 = x/y/z) and use the momentum slot kMom[axis] as the normal one; the other two momenta are tangential and are simply advected.

RiemannSolver is stateless and evaluates every face in one OpenMP-parallel loop. It also returns the largest wave speed $\max_f \max(|S_L|, |S_R|)$, which sets the CFL time step.

HLLC (Toro, Spruce & Speares 1994)

HLLC estimates three waves: the left acoustic wave $S_L$, the contact $S_M$ and the right acoustic wave $S_R$. It then builds intermediate "starred" states on each side of the contact. The Einfeldt wave-speed bounds are

$$S_L = \min(V_{n,L} - c_L,\ V_{n,R} - c_R), \qquad S_R = \max(V_{n,L} + c_L,\ V_{n,R} + c_R)$$

and the contact speed (Toro 2009, eq. 10.37) is

$$S_M = \frac{p_L - p_R + \rho_R V_{n,R}(S_R - V_{n,R}) - \rho_L V_{n,L}(S_L - V_{n,L})} {\rho_R(S_R - V_{n,R}) - \rho_L(S_L - V_{n,L})}$$

The flux is selected by wave ordering:

  • if $S_L \geq 0$: $\mathbf{F}^* = \mathbf{F}_L$
  • if $S_L < 0 \leq S_M$: $\mathbf{F}^* = \mathbf{F}_L + S_L(\mathbf{U}^*_L - \mathbf{U}_L)$
  • if $S_M < 0 \leq S_R$: $\mathbf{F}^* = \mathbf{F}_R + S_R(\mathbf{U}^*_R - \mathbf{U}_R)$
  • if $S_R < 0$: $\mathbf{F}^* = \mathbf{F}_R$

The scheme resolves isolated shocks, contacts and rarefactions exactly, and preserves positivity of density and pressure. Near-zero denominators are guarded with a sign-preserving floor of $10^{-14}$.

Low-Mach HLLC (Thornber et al. 2008)

Standard HLLC adds $O(1)$ dissipation to the velocity jump across each face. At low Mach number this is far larger than the physical $O(\mathrm{Ma}^2)$ pressure fluctuation, which causes odd-even decoupling and excessive diffusion. Thornber's fix scales the velocity jump by the local Mach number:

$$z = \operatorname{clip}\bigl(\max(\mathrm{Ma}_L, \mathrm{Ma}_R),\ 10^{-4},\ 1\bigr), \qquad u_L^* = \bar u + z\,\delta u, \quad u_R^* = \bar u - z\,\delta u$$

with $\bar u = \tfrac12(u_L+u_R)$ and $\delta u = \tfrac12(u_L - u_R)$ (and the same for $v$ and $w$). Standard HLLC is then applied to the modified states. Shock capturing is unaffected, because $z = 1$ above Mach 1.

Preconditioned HLLC (Weiss & Smith 1995)

At low Mach number the acoustic speeds $\pm c$ dwarf the flow speed, which makes the system stiff. Preconditioning replaces $c$ with a reduced reference speed:

$$V_r = \operatorname{clip}\bigl(V_n^2,\ (\mathrm{Ma}_{\rm cut}\,c)^2,\ c^2\bigr), \qquad \beta = \frac{V_r}{c^2}, \qquad \lambda_\pm = V_n\,\frac{1+\beta}{2} \pm \sqrt{\Bigl(\frac{1-\beta}{2}V_n\Bigr)^2 + V_r}$$

The $\lambda_\pm$ replace the Einfeldt bounds. The solver uses $\mathrm{Ma}_{\rm cut} = 0.1$; $\mathrm{Ma}_{\rm cut} = 1$ recovers standard HLLC exactly.

TVD slope limiters

A limiter $\phi(a, b)$ constrains the reconstruction slope so that no new extrema appear (the Total Variation Diminishing property). Its arguments are the upwind difference $a = W_i - W_{i-1}$ and the downwind difference $b = W_{i+1} - W_i$:

Limiter $\phi(a,b)$ Character
Minmod $\tfrac12(\operatorname{sgn}a + \operatorname{sgn}b)\min(\lvert a\rvert, \lvert b\rvert)$ most diffusive, unconditionally TVD
Van Leer $\dfrac{2ab}{a+b}$ if $ab > 0$, else 0 harmonic mean, smooth and symmetric (default)
Koren $\operatorname{minmod}\bigl(2a, \tfrac{2a+b}{3}, 2b\bigr)$ 3rd order in smooth regions
MC $\operatorname{minmod}\bigl(2a, \tfrac{a+b}{2}, 2b\bigr)$ most compressive, sharpest

All four return zero at extrema ($ab \le 0$) and stay inside the TVD region $|\phi| \le 2\min(|a|, |b|)$.

MUSCL reconstruction

MUSCL upgrades the 1st-order Godunov scheme to 2nd-order spatial accuracy. The primitive variables are reconstructed linearly, with limiting, on each side of every face before the Riemann problem is solved. At face $i+\tfrac12$:

$$W_{L,i+1/2} = W_i + \tfrac12\phi(a, b), \qquad W_{R,i+1/2} = W_{i+1} - \tfrac12\phi(a', b)$$

with $a = W_i - W_{i-1}$, $b = W_{i+1} - W_i$ and $a' = W_{i+2} - W_{i+1}$. The stencil needs two cells on each side of a face (kHaloDepth = 2), the same depth as the MPI halo exchange. Faces on a rank interface are therefore also reconstructed to 2nd order, and so are periodic boundary faces, through wrap-around halos. The other physical-boundary faces keep their 1st-order ghost states. In 3-D, reconstruct_3d applies the same 1-D reconstruction along x, y and z; each direction reads its own pair of halo slabs (Halos::l/r, b/t, f/bk).

Without limiting ($\phi = b$) the scheme is 2nd order but oscillatory near shocks. With limiting it is TVD and drops locally to 1st order at extrema.
